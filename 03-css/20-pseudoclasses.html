:first-child / :last-child

  • Elemento 1 (primero, en rojo)
  • Elemento 2
  • Elemento 3
  • Elemento 4 (último, en azul)

El primer y último elemento tienen colores especiales.

:nth-child

  • Elemento 1 (fondo alterno)
  • Elemento 2 (fondo alterno)
  • Elemento 3 (fondo alterno + borde amarillo)
  • Elemento 4 (fondo alterno)
  • Elemento 5 (fondo alterno)
  • Elemento 6 (fondo alterno + borde amarillo)

Fondos alternos y cada 3 elementos tienen borde izquierdo amarillo.

:not

  • Elemento normal (verde)
  • Elemento excluido (rojo y tachado)
  • Otro normal (verde)
  • Otro excluido (rojo y tachado)

Los elementos con clase .excluido se ven diferentes.
