Decoration

underline: Texto subrayado.

overline: Texto con línea superior.

line-through: Texto tachado.

underline wavy: Subrayado ondulado.

Transform

uppercase: Este texto está en mayúsculas.

lowercase: ESTE TEXTO ESTÁ EN MINÚSCULAS.

capitalize: cada palabra comienza con mayúscula.

none: Texto sin transformar.

Indent

1.5rem: Este párrafo tiene sangría pequeña en la primera línea. El resto del texto fluye normalmente.

3rem: Este párrafo tiene sangría mediana. La primera línea está más desplazada.

6rem: Este párrafo tiene sangría grande. La primera línea está muy desplazada.

Spacing

word-spacing:

normal: Esto es un texto normal.

0.5rem: Espacio amplio entre palabras.

1rem: Espacio aún más amplio.

2rem: Espacio muy grande.

letter-spacing:

normal: Letras normales.

-0.05em: Letras más juntas.

0.15em: Letras separadas.

0.4em: Letras muy separadas.
